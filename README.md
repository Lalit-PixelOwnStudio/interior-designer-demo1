# Interior Core website

Static site (HTML, CSS, JavaScript), hosted on GitHub Pages:
https://lalit-pixelownstudio.github.io/interior-designer-demo1/

HTML files hold only markup. All styling lives in `css/` and all behaviour in
`js/`; there are no inline styles, `<style>` blocks, inline scripts or
`onclick`/`onerror` handlers in the pages.

## Folder structure

```
index.html            Home page (the source for shared sections, header and footer)
about.html            About page
services.html         Generated by scripts/build-pages.py
projects.html         Generated
pricing.html          Generated
contact.html          Generated
materials.html        Generated
project.html          Generated (case-study page, filled in by js/pages/case-study.js)
404.html              Generated

partials/             HTML for sections that only appear on inner pages
  estimator.html  visit.html  quiz.html  materials.html  404.html

css/
  base/               tokens (colours, fonts), utilities, nav, shared section
                      pieces, footer, responsive rules, intro, page transitions
  components/         lightbox, project viewer
  sections/           one file per section: hero, about, gallery, portfolio,
                      before-after, services, process, reviews, pricing, faq,
                      contact, guarantees, brands
  pages/              page-only styles: about, inner pages, estimator,
                      case-study, visit, materials, quiz, 404
  style.min.css       BUILT: every file above joined in order and minified

js/
  config.js           Phone, WhatsApp, email, address, studio hours (edit here)
  data.js             Projects, case studies, before/after rooms (edit here)
  core/               head.js (runs before paint), transitions.js,
                      image-fallback.js, main.js
  components/         lightbox.js
  sections/           before-after, gallery, portfolio, reviews, pricing, faq,
                      contact, process
  pages/              estimator, visit, quiz, materials, case-study, about,
                      not-found
  site.min.js         BUILT: every script (except core/head.js) joined in
                      order and minified

img/                  Optimised images and video used by the site
  brand/  brands/  hero/  projects/  before-after/  materials/
Assets/               Original photos and video (not loaded by the site)

scripts/
  build-pages.py              Builds the inner pages, css/style.min.css and js/site.min.js
  optimize-images.py          Makes img/ from Assets/
  make-material-swatches.py   Draws the material-library swatches
```

## Making changes

1. Edit the files in `css/`, `js/`, `partials/` or `index.html` / `about.html`.
2. Run `python scripts/build-pages.py`. It rebuilds the inner pages and the two
   minified files. Raise `VERSION` at the top of the script so browsers fetch
   the new CSS and JS.
3. Commit and push. GitHub Pages updates in a minute or two (refresh with
   Ctrl+Shift+R).

The order of stylesheets and scripts is set by `CSS_FILES` and `JS_FILES` in
`scripts/build-pages.py`; add new files there. Minifying uses esbuild through
`npx` (Node.js); without it the files are joined but not minified.

If the site moves to the root of its own domain (for example on Vercel),
change `SITE_BASE` in `scripts/build-pages.py` to `"/"` and rebuild, so the
404 page finds its CSS and JS.
